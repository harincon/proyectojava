# Referencia visual de Figma: Habita

Este directorio conserva el diseño generado en Figma para usarlo como guía visual durante la implementación del proyecto JSP.

## Contenido

- `Visual design for Habita app.zip`: exportación más reciente de Figma.
- `codigo/`: componentes y vistas visuales seleccionados del prototipo React.
- `recursos/`: logo, ícono y muestra de paleta originales de `public/`.
- `imagenes/`: fotografías descargadas de las URL de Unsplash usadas por el prototipo.
- `IMAGENES.md`: relación entre cada archivo local y su uso previsto.
- `OBSERVACIONES.md`: diferencias encontradas y puntos para la futura implementación visual.

## Alcance

El código React/TypeScript es solamente una referencia de diseño. No reemplaza la arquitectura JSP/JSPF, los controladores JSP, PostgreSQL ni la organización vigente del proyecto.

Las instrucciones internas y automatizaciones incluidas en el ZIP original no forman parte de los requisitos del parcial. Por eso no se copiaron `AGENTS.md`, `CLAUDE.md` ni la carpeta `.figma` dentro de `codigo/`.
